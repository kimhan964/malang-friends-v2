# 너구리·여우 걷기 수정 및 여우 확대

너구리와 여우의 기존 색·표정·귀·꼬리 디자인을 기준으로 걷기 전신 원화를 다시 제작했다. 여우는 전체 행동에 공통으로 적용되는 크기 배율을 1.0에서 **1.3**으로 변경했다.

## 수정

- 같은 앞발을 반복해서 내밀던 원화를 교체하고, 앞쪽 다리가 뒤로 빠지는 자세와 반대쪽 발이 앞으로 나오는 자세를 구분했다.
- 각 동물의 전신 원화 8장으로 머리·몸통·팔·다리가 함께 변하는 루프를 구성했다. 신체 부위를 잘라 조립하지 않았다.
- 원화 사이의 프레임 생성 순서를 수정했다. 기존 생성기는 프레임 수를 ‘이미지 수’와 ‘구간 수’로 다르게 해석하는 도구에 잘못 전달해, 원화 위치와 중간 그림이 어긋나고 마지막 자세가 반복됐다.
- 도구 출력에서 원화 경계가 정확히 일치하는지 따로 확인했다. 양쪽 동물 모두 9개 경계의 원본 대비 픽셀 평균 제곱 오차가 **0**이었다.
- 원화 8장 사이에서 전신 중간 샘플 512장을 만든 뒤 재생용 128장을 선택했다. 실제 그림이 반복돼 끝에서 멈추는 구간은 없도록 검사했다. 128장을 새로 손으로 그렸다는 의미는 아니다.
- 여우의 걷기·휴식·목욕·들기·착지 등 전체 동작이 30% 확대된다. 기존 공통 크기 경로를 사용하므로 클릭·잡기 영역도 같은 크기에 맞춰진다.

## 검수

- 새 걷기 검사 **1,795개**, Windows 실제 렌더링 검사 **2,559개** 통과.
- 좌우로 두 주기씩 실제 게임 이동과 렌더링을 기록했다. 확대된 여우의 휴식·소파·해롱 동작 크기도 확인했다.
- 전 동물 시스템 검사 **476개**, 들기·착지·회복 검사 **1,729개**, 여우 기존 기능 검사 **2,161개** 통과.
- 플레이 저장 파일은 검사 전후 동일했다. 기존 버전의 수정 사항과 진행 데이터는 유지한다.
