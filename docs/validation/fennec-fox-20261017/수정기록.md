# 사막여우 디자인과 걷기 재제작 · 2026-10-17

큰 귀, 둥근 볼과 작은 표정, 연한 살구색·아이보리 털로 여우를 바꿨습니다. 기존 동물들의 굵고 따뜻한 선과 단순한 그림체를 유지합니다. 여우 걷기와 기본·들기·가구·일상·특수 행동 23종을 같은 디자인으로 연결했습니다.

걷기는 접지·체중 싣기·낮은 발 교차·다음 접지의 양발 역할을 여덟 전신 원화로 나누었습니다. 4개 자세 사이를 길게 늘이던 방식에서 벗어나 보폭을 줄이고 실제 지지 발 위치로 전체 그림의 기준을 정렬했습니다. 팔다리나 얼굴을 잘라 움직이는 리깅은 쓰지 않았습니다.

반복 경계를 넘을 때 남은 프레임 시간을 소비하도록 하여 매 반복마다 조금씩 멈칫하던 이동을 수정했습니다. 새 동작의 이동 속도는 기존과 같습니다. 이 연속 이동은 새 여우 동작에만 적용됩니다.

- 전신 원화: 8개, 게임 아틀라스: 128장
- 성체 기본 걷기: 전체 주기 약 1.019초, 실제 평균 이동 26.16px/초
- 큰 보폭은 이전 131.24에서 74.50 원화 픽셀로 줄이고, 이동과 발 위치에 맞춰 재생 시간을 함께 조절했습니다.

검수는 실제 `main.gd`와 같은 `smooth_walk_enabled=true`를 명시하여 수행했습니다. 앞선 여우·수달 검수의 일부 독립 캐릭터가 다른 이동 설정을 사용했던 점을 바로잡았습니다.

- 30/60/144Hz 및 한 주기보다 긴 프레임에서 누적 이동 거리와 시간이 맞는지 검사
- 좌우 각각 세 주기, 실제 게임의 `desktop_pet_view.gd`와 `advance_travel`로 촬영
- 23개 행동의 새 그림 경로·읽기·잘림·빈 프레임 검사
- 대기·쓰다듬기·수면·먹기와 가구 진입 전환을 게임 표시 기능으로 확인
- 원화와 중간 그림에서 팔 중복·발 윤곽을 육안 확인. 팔이 중복된 초기 시안은 제외

`fox-walk-right.gif`, `fox-walk-left.gif`는 촬영한 전체 화면에 동일한 고정 자르기와 3배 확대를 적용한 영상입니다. 캐릭터 부위를 수정하거나 프레임마다 위치를 보정한 영상이 아닙니다. 세 주기 뒤 처음 위치로 돌아가는 것은 GIF 재생 반복입니다.

자동 수치 검사는 동작의 자연스러움을 완전히 판정하지 않습니다. 실제 크기·확대 화면과 중간 프레임을 함께 확인했습니다. 이 기록은 현재 PC의 Godot/OpenGL 환경을 기준으로 합니다.
