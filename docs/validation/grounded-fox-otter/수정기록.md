# 여우·수달 걷기와 디딤 수정

양발이 번갈아 앞에 나오는 접지 자세와 낮은 교차 자세를 전신 원화로 제작했습니다. 팔다리 분리 없이 전체 그림을 보간하고 디딤 부근에서 연속적으로 느려지도록 재생 시점을 조정했습니다.

| 동물 | 한 발 교체 간격 | 두 발 전체 주기 | 평균 이동 속도 |
|---|---:|---:|---:|
| 여우 | 0.897초 | 1.795초 | 26.16px/초 (기존 유지) |
| 수달 | 1.046초 | 2.093초 | 26.16px/초 (기존 유지) |

이 수치는 성체 기본 걸음 기준입니다. 성장 크기나 행동에 따라 이동량과 속도가 달라집니다. 달리기는 별도의 빠른 이동·체공 동작을 유지합니다.

실제 `desktop_pet_view.gd` 표시와 `advance_travel` 이동을 사용하여 좌우 각각 두 주기를 촬영했습니다. 영상은 촬영한 전체 화면을 두 배로 확대한 것이며 캐릭터 부위를 수정하지 않았습니다. 촬영은 초당 30장, 이동 계산은 초당 60회입니다.

- `fox-walk.gif`, `otter-walk.gif`: 실제 게임 렌더링 확인 영상
- `native.json`: 좌우 연속 이동, 새 그림 사용, 잘림·빈 그림, 걷기와 달리기 속도 구분 검사
- `headless.json`: 같은 이동 검사의 화면 없는 실행 결과
- `review.png`: 한 주기의 주요 화면 비교

원화와 중간 프레임의 양발 위치·윤곽을 육안 확인했습니다. 수치 검사는 연속 이동과 기능 연결을 확인하며 애니메이션의 자연스러움을 완전히 판정하지 않습니다.

생성 도구는 내장 image_gen입니다. 최종 프롬프트와 원화 출처는 `docs/art/grounded-fox-otter/generation.json`에 기록했습니다.
